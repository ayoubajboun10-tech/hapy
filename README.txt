FREE PUBLISHING WITH GITHUB PAGES:
1. Create a new public GitHub repository, e.g. marwa-birthday.
2. Upload BOTH index.html and birthday-video.mp4 to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for deployment. Your page URL will look like:
   https://YOUR-USERNAME.github.io/marwa-birthday/
